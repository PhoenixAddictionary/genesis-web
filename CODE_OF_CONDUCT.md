# Code of Conduct

The short version: be a good shipmate.

## Rules of the deck

1. **Sources or silence applies to people too.** Claim what you can show.
   If you are guessing, say you are guessing.
2. **No harassment, no slurs, no dogpiling.** Critique work, not people.
3. **No secrets in the repos.** No tokens, no credentials, no personal data
   about anyone — contributor, user, or bystander.
4. **The license is part of the deal.** Respect the split in LICENSING.md
   (code vs. content) when you reuse anything.
5. **Disputes go to the maintainer.** The project owner's call is final.
   Sustained bad faith gets you put ashore.

## Enforcement

Report conduct issues by opening an issue (no names needed in public if you
prefer — describe the behavior) or through GitHub's private reporting. The
maintainer reads everything and answers in the open where possible.

This code is deliberately short. It is not a legal document; it is the deck
rules of a small ship. If the ship grows, the rules grow with it.
